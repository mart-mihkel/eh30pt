# Est-Health 30 Prompt Tuning

## Development

Use [just](https://just.systems/man/en/) as the command runner and [uv](https://docs.astral.sh/uv/getting-started/installation/) as the python project manager.

Set up the environment and pre-commit hooks with

```bash
just sync
```

The application is a command line interface installed in the virtualenv, see `cli --help`.

See `just --list` for all development commands.
